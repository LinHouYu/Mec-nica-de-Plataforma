## 🕹️ Gameplay Tutorial / 游戏游玩教程 / Tutorial de Juego

### 🇨🇳 中文说明
- ⌨️ **移动**：使用 **WASD** 键  
- 🟦 **跳跃**：按 **空格键**，支持 **二段跳**  
- 💾 **存档**：每一关都会自动保存  
- 🔄 **复活**：死亡后会从上一关卡复活  

---

### 🇺🇸 English Description
- ⌨️ **Movement**: Use **WASD** keys  
- 🟦 **Jump**: Press **Spacebar**, double jump available  
- 💾 **Save**: Each level is automatically saved  
- 🔄 **Respawn**: Upon death, you respawn at the last completed level  

---

### 🇪🇸 Español
- ⌨️ **Movimiento**: Usa las teclas **WASD**  
- 🟦 **Salto**: Pulsa la **barra espaciadora**, con doble salto disponible  
- 💾 **Guardado**: Cada nivel se guarda automáticamente  
- 🔄 **Reaparición**: Al morir, reapareces en el último nivel superado
